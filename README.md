# DSCI 552 Homework 4

Binary (bending vs other) and multiclass (7 activity) classification on the AReM time series with logistic regression, RFE and L1-penalized selection, and naive Bayes, plus written solutions to ISLR exercises 4.8.3 and 4.8.7.

Open `notebook/Liau_Olivia_HW4.ipynb` in Jupyter and run `Cell -> Run All` from a fresh kernel; the notebook reads the data with relative paths (`../data/AReM/...`), so run it from the notebook location inside this repo.
